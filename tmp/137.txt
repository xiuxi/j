Branching and Looping
Computers derive much of their power from their
ability to execute code selectively and from the
speed at which they execute repetitive algorithms.
Programs in high-level languages like Ada, C++, or
Pascal use if-then, if-then-else, and case structures
to execute code and loop structures selectively, such
as while (pre-test) loops, until (post-test) loops, and
for (counter-controlled) loops to repetitively execute code. Some high-level languages have a goto
statement for unconditional branching. Somewhat
more primitive languages (like older versions of
BASIC) depend on fairly simple if statements and an
abundance of goto statements for both selective
execution and looping.
The 80x86 assembly language programmer’s job is similar to the old BASIC programmer’s
job. The 80x86 microprocessor can execute some
instructions that are roughly comparable to for
statements, but most branching and looping is done
with 80x86 statements that are similar to, but even
more primitive than, simple if and goto statements.
The objective of this chapter is to describe the
machine implementation of language structures
such as if-then, if-then-else, while, until, and for.
