push  eax

6.2 Procedure Body, Call and Return
The word procedure is used in high-level languages to describe a subprogram that is
almost a self-contained unit. The main program or another subprogram can call a procedure by including a statement that consists of the procedure name followed by a parenthesized list of arguments to be associated with the procedure’s formal parameters.
