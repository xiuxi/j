3. Each part of this problem contains a design with a for loop. Assume
that sum references a doubleword in the data segment and that the
value of count is in the ECX register. Give a fragment of 80x86 code that
implements the design.
(a) sum := 0;
for count := 1 to 100 loop
add count to sum;
end for;
(b) sum := 0;
for count := –10 to 50 loop
add count to sum;
end for;
(c) sum := 1000;
for count := 100 downto 50 loop
subtract 2*count from sum;
end for;
