The assembly listing for the code segment shows, in hex, the offset and the
object code of each instruction. Some assemblers may also show the offset for a macro,
that is, the address of the first instruction to which it expands. The first byte of the
machine code for each instruction is called its opcode (operation code). By looking at an
opcode as the program executes, the 80x86 knows what kind of operation is to be done
and whether or not there are more bytes of the instruction. The object code for a single
instruction can be from one to 16 bytes long.
