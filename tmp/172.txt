5. Write a complete 80x86 assembly language program to simulate a simple calculator. The calculator does addition and subtraction operations
and also accepts commands to clear the accumulated value or to quit.
Implement the following design.
total := 0;
forever loop
display "number? ";
input number;
display "action (+, -, c or q) ? ";
input action;
if (action = '+')
then
add number to total;
elseif (action = '-')
then
subtract number from total;
elseif (action = 'c') or (action = 'C')
then
total := 0;
elseif (action = 'q') or (action = 'Q')
then
exit loop;
else
display "Unknown action";
