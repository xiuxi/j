Two “move” instructions are somewhat similar to the above “convert” instructions. These instructions copy an 8-bit or 16-bit source operand to a 16-bit or 32-bit destination, extending the source value. The movzx instruction always extends the source
value with zero bits. It has the format
movzx   register, source
The movsx instruction extends the source value with copies of the sign bit. It has a similar format
movsx   register, source
