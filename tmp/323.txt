push   eax
mov    eax, dword1
xchg   eax, dword2

Figure 9.9 Macro to swap two memory words
expands to
; put sum of two doubleword parameters in EAX
mov    eax,
add    eax, value
The comma in the macro call separates the first missing argument from the second argument value. An empty argument replaces the parameter nbr1. The assembler will again
report an error, this time for the illegal mov instruction.
Figure 9.9 shows the definition of a macro swap that will exchange the contents
of two doublewords in memory. It is very similar to the 80x86 xchg instruction that will
not work with two memory operands.
As with the add2 macro, the code generated by calling the swap macro
depends on the arguments used. For example, the call
swap  [ebx], [ebx+4]    ; swap adjacent words in array
expands to
; exchange two doublewords in memory
push   eax
mov    eax, [ebx]
xchg   eax, [ebx+4]
mov    [ebx], eax
pop    eax
