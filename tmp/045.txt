Assembly language statements can be entered using either uppercase or lowercase letters. Normally the assembler does not distinguish between uppercase and lowercase. It can be instructed to distinguish within identifiers, but this is only needed when
you are communicating with a program written in a language that is case-sensitive.
Mixed-case code is easier for people to read than code written all in uppercase or lowercase. All uppercase code is especially difficult to read. One convention is to use mostly
lowercase source code except for uppercase directives. This is the convention that will
be followed for programs in this book.
