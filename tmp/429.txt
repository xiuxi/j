Figure 12.5 shows a program that prompts for inputs the name of a file and then
displays the contents of the file on the console. It includes two new kernel32 function
prototypes, CreateFileA and CloseHandle. In spite of its name, CreateFileA is used both
to open an existing file or to create a new file. CloseHandle is used to close a file.
