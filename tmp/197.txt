Figure 6.2 pop instructions
Pop instructions do the opposite job of push instructions. Each pop instruction
has the format
pop destination
where destination can reference a word or doubleword in memory, any register 16, any
register 32, or any segment register except CS. (The push instruction does not exclude
CS.) The pop instruction gets a word-size value from the stack by copying the word at
the address in ESP to the destination, then incrementing ESP by 2. Operation for a doubleword value is similar, except that ESP is incremented by 4. Figure 6.2 gives information about pop instructions for different destination operands.
