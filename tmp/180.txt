2. A Pythagorean triple consists of three positive integers A, B, and C
such that A2 + B2 = C2. For example, the numbers 3, 4, and 5 form a
Pythagorean triple since 9 + 16 = 25. Write a complete 80x86 program to
input a value for C and then display all possible Pythagorean triples
with this value for C, if any. For example, if 5 is entered for the value of
C, then the output might be
A          B          C
3          4          5
