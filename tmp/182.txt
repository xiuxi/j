In the 80x86 architecture any of the general registers EAX, EBX, ECX, and EDX or the
index registers EDI and ESI are appropriate for use as a “pointer.” The ESI and EDI registers are often reserved for use with strings, which are usually arrays of characters. String

; input a collection of numbers
; report their average and the numbers which are above average
; author:  R. Detmer
; date:  revised 9/97
.386
.MODEL FLAT
INCLUDE io.h
ExitProcess PROTO NEAR32 stdcall, dwExitCode:DWORD
cr          EQU    0dh   ; carriage return character
Lf          EQU    0ah   ; linefeed character
maxNbrs     EQU    100   ; size of number array
.STACK      4096
.DATA
