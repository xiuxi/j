The number of characters read will normally be smaller than the size of the
buffer to receive the characters. If it is larger, values in memory following the input buffer
may be destroyed. An additional consideration with console input is that carriage return
and linefeed characters are added to the characters that you key in. That is, if you type
six characters and then press Enter, eight characters will actually be stored in the input
buffer—the six characters plus the carriage return and linefeed.
In the program from Fig. 12.3, there is a blank line of output before the line of
lowercase characters, which is because of the CR/LF that is in memory before the input
buffer. The starting address for output includes these two additional characters and the
character count has been increased by two to include these characters. Because the
original character count includes the CR/LF at the end of the characters read in, there
will also be a skip to a new line after the characters are displayed.
