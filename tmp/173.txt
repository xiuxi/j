5.4 for Loops in Assembly Language
Often the number of times the body of a loop must be executed is known in advance,
either as a constant that can be coded when a program is written, or as the value of a
variable that is assigned before the loop is executed. The for loop structure is ideal for
coding such a loop.
The previous section showed how to translate a for loop into a while loop. This
technique always works and is frequently the best way to code a for loop. However, the
80x86 microprocessor has instructions that make coding certain for loops very easy.
Consider the following two for loops, the first of which counts forward and the
second of which counts backward.
for index := 1 to count loop
... { body of loop }
end for;
and
for index := count downto 1 loop
... { body of loop }
end for;
The body of each loop executes count times. If the value of index is not needed for display or for calculations within the body of the loop, then the loop that counts down is
equivalent to the loop that counts up, although the design may not be as natural. Backward for loops are very easy to implement in 80x86 assembly language with the loop
instruction.
