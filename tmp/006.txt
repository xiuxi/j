1.2 Character Codes
Letters, numerals, punctuation marks, and other characters are represented in a computer by assigning a numeric value to each character. Several schemes for assigning
these numeric values have been used. The system commonly used with microcomputers
is the American Standard Code for Information Interchange (abbreviated ASCII and pronounced ASK-ee).
The ASCII system uses seven bits to represent characters, so that values from
000 0000 to 111 1111 are assigned to characters. This means that 128 different characters
can be represented using ASCII codes. The ASCII codes are usually given as hex numbers
from 00 to 7F or as decimal numbers from 0 to 127.1 Appendix A has a complete listing of
