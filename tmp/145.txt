The following 80x86 code fragment implements this design.
add   balance,eax  ; add value to balance
jns   elseIfZero   ; jump if balance not negative
...                ; code for negative balance
jmp   endBalanceCheck
elseIfZero: jnz   elsePos      ; jump if balance not zero
...                ; code for zero balance
jmp   endBalanceCheck
elsePos:    ...                ;code for positive balance
endBalanceCheck:
Appropriate flags are set or cleared by the add instruction. No other instruction
shown in the above code fragment changes the flags. The design checks first for (balance < 0). The code does this with the instruction
jns   elseIfZero
which says to jump to elseIfZero if the sign flag is not set; that is, if (balance < 0) is
not true. The code following this instruction corresponds to statements following the first
then in the design. The statement
jmp   endBalanceCheck
